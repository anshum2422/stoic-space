# stoic-space

NASA picture viewer with 3 themes.

## Live
https://anshum2422.github.io/stoic-space/

## Features
- 3 themes (Stoic / Sakura / Simple)
- Keyboard shortcuts (S = theme, Space = new pic)
- Nothing OS font

## Tech
- HTML, CSS, JS
- NASA API
- GitHub Pages
